# StudioSpace – Client

🌐 **Live Website:** https://your-client-live-url.com

**StudioSpace** is a modern and user-friendly studio booking platform that allows users to discover studios, explore facilities, and manage their bookings easily.

## ✨ Key Features

- **User Authentication:** Register and log in using Email/Password.
- **Google Login:** Secure authentication using Google.
- **Studio Discovery:** Browse featured and available studios.
- **Studio Details:** Explore studio information, images, and facilities.
- **Booking Management:** Book studios and manage reservations.
- **Wishlist:** Save favorite studios for future visits.
- **User Profile:** View and manage personal account information.
- **Responsive Design:** Compatible with desktop, tablet, and mobile devices.

## 🛠️ Technology Stack

- Next.js
- React.js
- TypeScript
- Tailwind CSS
- Axios
- React Hot Toast
- Google Identity Services

## 📦 Local Setup Instructions

### 1. Clone the Repository

```bash
git clone YOUR_CLIENT_REPOSITORY_URL
cd StudioSpace-Client
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your_google_client_id
```

### 4. Run the Development Server

```bash
npm run dev
```

Open http://localhost:3001 in your browser.
